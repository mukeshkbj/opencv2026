| Criterion (weight) | Strongest evidence | Gap |
|---|---|---|
| Technical execution (30) | A full registration and change pipeline on OpenCV 5; an agent loop with measured triage; signed, verifiable evidence; 11 tests; three benchmarks with seeds | No labelled set of real damage pairs. The hybrid benchmark (recall 0.24) shows the distance to real damage. |
